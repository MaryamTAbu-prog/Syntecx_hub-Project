# Syntecx_hub-Project
# Student Performance Analysis

## Project Overview

This project explores student academic performance using a dataset of 100 students. The analysis focuses on Mathematics, Reading and Writing scores, as well as how student demographics and test preparation records relate to academic performance.

The goal was to examine performance patterns, identify areas that may need attention and present findings that can support better academic decisions.

## Project Objectives

- Examine students' performance across the three subjects.
- Compare average scores across student groups.
- Identify students with particularly high or low overall scores.
- Explore differences in performance based on gender and parental education.
- Examine the relationship between test preparation records and academic performance.

## Dataset

The dataset contains 100 student records and the following information:

- Student ID
- Gender
- Ethnicity
- Parental Education
- Test Preparation
- Mathematics Score
- Reading Score
- Writing Score

## Analysis Performed

- Data inspection and cleaning.

- Comparison of performance across student groups.
- Data visualisation.
- Interactive Dashboard


## Key Findings

- Mathematics had the highest average score at 62.51.
- Reading had the lowest average score at 60.49.
- The overall class average was 61.18.
- Students with completed test preparation had an average score of 66.34, compared with 57.59 for records marked "Not Recorded".
- Female and male students had very similar average scores.

**Data limitation:** "Not Recorded" represents missing test preparation information. It does not confirm that those students did not prepare for their tests.
